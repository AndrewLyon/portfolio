Splitting a column

maybe you need to split a column based on the values it holds

sites_df <- data.frame(site = c("HAW-101",
                                "HAW-103",
                                "OAH-320",
                                "OAH-219",
                                "MAU-039"))

sites_df %>%
    separate(site, c("island", "site_number"), "-")#this creates a column named island and another named site_number based on the values of site. It takes the '-' and uses that as it's split point

have a list of things that you need to become just one thing? easy! we do the same but in reverse

dates_df <- data.frame(
    year = c("1930",

dates_df %>%

Simplified pipeline

You can combine all of the steps above into a single chunk

catch_original <- read_csv("https://knb.ecoinformatics.org/knb/d1/mn/v2/object/df35b.302.1") #generates the data objecct catch_original from the csv online

mean_region <- catch_original %>% #creates catch_original
  select(-All, -notesRegCode) %>%  #selects all the data except notesRegCode
  mutate(Chinook = if_else(Chinook == "I", "1",  Chinook)) %>%  #converts all I values into 1
  mutate(Chinook = as.numeric(Chinook)) %>% 
  #converts the va;lues of Chinook into nimbers
  pivot_longer(-c(Region, Year), #pivots the table based on all columns except Region and Year
               names_to = "species", #names the columns into one called species
               values_to = "catch") %>% #moves all of the old cloumn numbers into one called catch
  mutate(catch = catch*1000) %>% #multiplies the catch number by 1000
  group_by(Region) %>% #groups the data by region
  summarize(mean_catch = mean(catch)) %>% #summarizes the average catch into a new column called mean_catch 
  arrange(desc(mean_catch)) #arranges the values of the row based on descending (highest to lowest) values of mean_catch
